README

Este es un modelador numérico realizado en el ambiente de programación
MATLAB donde se simulan procesos de transferencia de calor y de masa en
medios porosos, a través de la resolución numérica de las ecuaciones de
calor convectivo y de vorticidad mediante el método de diferencias
finitas.

Dicho modelador se puede usar para modelar yacimientos geotérmicos con
fines académicos y/o de investigación. El código es abierto con la
finalidad de que el usuario se sienta libre de modificarlo, ya sea
añadiéndole una interfaz gráfica interactiva (GUI), modificando las
condiciones de frontera, leer archivos de datos con los datos del
modelo, etc. (solo si el usuario tiene conocimiento de la elaboración
de scripts y la sintaxis del lenguaje del entorno MATLAB, así como del
proceso de resolución numérica de EDP por el método de diferencias
finitas).

A lo largo de los scripts del algoritmo principal y sus subrutinas, se
colocaron comentarios auxiliares con el fin de orientar al usuario en
el funcionamiento de los mismos, de los datos a manejar y de los procesos
dentro de una simulación, con el propósito de que el usuario entienda
dicho funcionamiento.
